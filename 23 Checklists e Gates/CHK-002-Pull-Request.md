# CHK-002 — Pull request

- [ ] Objetivo, contexto e critérios de aceite estão descritos.
- [ ] Mudanças geradas por agentes estão identificadas.
- [ ] O diff é revisável e não contém mudanças não relacionadas.
- [ ] Testes automatizados e verificações de segurança passaram.
- [ ] Dependências e permissões alteradas estão explícitas.
- [ ] Migração e rollback foram descritos quando necessários.
- [ ] Há revisão humana independente para mudança crítica.
- [ ] Evidências e riscos residuais estão vinculados.

Falha em gate obrigatório: **não realizar merge**.
