# CHK-001 — Pré-commit

- [ ] A alteração está vinculada a uma tarefa e objetivo.
- [ ] O diff contém somente mudanças dentro do escopo.
- [ ] Não existem segredos, credenciais ou dados pessoais desnecessários.
- [ ] Formatação, lint e testes relevantes foram executados.
- [ ] Dependências novas foram justificadas e avaliadas.
- [ ] Erros e verificações não foram ocultados.
- [ ] A evidência dos testes está disponível.
- [ ] Riscos residuais foram registrados.

Falha em segredo ou alteração não autorizada: **bloquear**.
