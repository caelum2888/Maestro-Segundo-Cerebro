# Maestro — Segundo Cérebro

Este diretório é um vault portátil do Obsidian para o projeto **Maestro — Plataforma de Orquestração Humano–IA**.

## Como instalar na VM

1. Copie ou descompacte esta pasta na máquina virtual Oracle.
2. Abra o Obsidian.
3. Selecione **Open folder as vault**.
4. Escolha a pasta `Maestro-Segundo-Cerebro-Obsidian`.
5. Abra [[00-HOME]].
6. Em **Settings → Core plugins → Templates**, configure `99 Sistema/Templates` como pasta de templates.
7. Configure `03 Recursos e referências/Anexos` como pasta padrão de anexos, caso desejado.

O vault não depende de plugins comunitários. Links, propriedades e templates utilizam recursos nativos do Obsidian.

## Regras de uso

- Capture rapidamente em [[00 Inbox/INBOX]].
- Processe a Inbox transformando cada item em uma nota atômica.
- Separe fato, inferência, recomendação, decisão, risco e pergunta.
- Nunca registre segredos, credenciais ou dados pessoais sem necessidade e autorização.
- Use os templates de `99 Sistema/Templates`.
- Consulte [[99 Sistema/00-COMANDOS]] para operar o cérebro com um agente.
