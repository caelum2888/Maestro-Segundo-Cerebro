# Inbox

Registre sinais rapidamente. Não organize durante a captura.

- [ ] 

## Regra de processamento

Para cada item, determine:

1. É fato, inferência, recomendação, decisão, risco, pergunta ou evidência?
2. Qual é a origem e a data?
3. Qual é a confiança?
4. A qual nota ou área ele se conecta?
5. Qual ação ou decisão resulta dele?

Depois, mova o conteúdo para uma nota permanente e marque o item como processado.
